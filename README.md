# statistical_testing

This code conducts statistical tests for each unique spraying event (i.e., combo of date, region, and spraying) to determine whether the event is associated with a statistically significant change in the number of olive fruit flies. The statistical tests include a Shapiro-Wilk test, a Student's t-test and a Mann-Whitney U test. 

It includes the finished/final version of code in the main branch, and previous versions in the prev_versions branch.
